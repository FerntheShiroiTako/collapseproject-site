Add Collapse to your server

You need Manage Server in the server you're adding it to.

  1. Invite the bot

    Choose your server on Discord's invite page.

    Open the invite page →

  2. Run /setup

    Paste your Rayward key, and a Bloxlink key if you have one. Then choose your mod role, your mod channel and who can run sweeps. The setup guide covers each option.

  3. Click Test & Finish

    Collapse tries your keys and its own permissions, and tells you what to fix. Dry run stays on until you turn it off in /config.

Help

Ask questions, report bugs and read announcements in the support server. If you'd rather not handle API keys yourself, the team can enter your own keys for you. Every server needs its own Rayward key.
